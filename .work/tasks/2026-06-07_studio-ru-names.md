# Developer — Sanity Studio: убрать дубль языков в названиях, оставить только русский

**Статус:** К выполнению
**Приоритет:** Средний
**Сложность:** S
**Ревью:** Нет (self-verify: `cd studio && npx tsc --noEmit`)
**Модель:** haiku
**Двойной план:** Нет
**Создана:** 2026-06-07

---

## Goal

В сайдбаре Studio сущности подписаны двуязычно: «Hero / Главная», «About / О себе»,
«Contacts / Контакты» (раздел «Разделы» уже только по-русски). Пользователь хочет
**только русские** названия — без английского префикса. Делаем подписи Studio
одноязычными (русскими).

## Scope

- **Делаем** — заменить дублирующие подписи на русские в 4 файлах:

  1. `studio/sanity.config.ts` — desk-структура (3 пункта меню):
     - `.title('🏠 Hero / Главная')` → `.title('🏠 Главная')`
     - `.title('📄 About / О себе')` → `.title('📄 О себе')`
     - `.title('📞 Contacts / Контакты')` → `.title('📞 Контакты')`
     - Заодно поправь комментарии-разделители (`// === Hero / Главная ... ===` и т.п.)
       на русские для единообразия. Пункт «🎼 Разделы» НЕ трогать (уже ок).

  2. `studio/schemaTypes/siteSettings.ts`:
     - `title: 'Hero / Главная'` → `title: 'Главная'`
     - preview fallback `title || 'Hero / Главная'` → `title || 'Главная'`

  3. `studio/schemaTypes/aboutSection.ts`:
     - `title: 'About / О себе'` → `title: 'О себе'`
     - preview fallback `title || 'About / О себе'` → `title || 'О себе'`

  4. `studio/schemaTypes/contactSettings.ts`:
     - `title: 'Contacts / Контакты'` → `title: 'Контакты'`
     - preview fallback `title || 'Contacts / Контакты'` → `title || 'Контакты'`

- **Не делаем:**
  - НЕ трогать названия полей внутри документов — они уже русские
    («Имя», «Роль (подзаголовок)», «E-mail» и т.д.).
  - НЕ трогать метки `'EN'` / `'RU'` в `localeString`/`localeText`/`localeRichText`
    (`studio/schemaTypes/locale.ts`) — это подписи языковых инпутов, не дубли.
  - НЕ менять `name`-идентификаторы типов/полей (это контракт данных, сломает Sanity).
    Меняем ТОЛЬКО человекочитаемые `title` и preview-строки.
  - НЕ трогать фронт, `CONTRACT.md`, GROQ — это чисто Studio-подписи.

## Как проверить
- `cd studio && npx tsc --noEmit` — без ошибок типов.
- Grep по `studio/`: строк `Hero /`, `About /`, `Contacts /` не осталось
  (кроме, возможно, англоязычных `description`-примеров вроде «Например: About» — их НЕ трогаем).
